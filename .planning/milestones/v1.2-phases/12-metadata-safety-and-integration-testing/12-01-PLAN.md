Implementation:
```java
/**
 * Checks if RBAC denies the current user access to sys.privileges.
 * Only ADMIN members may read this table. Non-admin users receive null (table not found).
 *
 * @param key the namespace key being accessed
 * @return true if access is denied (user is non-admin accessing sys.privileges)
 */
private boolean isRbacDeniedForSysPrivileges(NamespaceKey key) {
    // Only applies to sys.privileges specifically
    if (!"sys".equalsIgnoreCase(key.getRoot())
            || !"privileges".equalsIgnoreCase(key.getLeaf())) {
        return false;
    }
    // Feature flag OFF -> allow (RBAC disabled)
    if (dremioConfig == null || !dremioConfig.getBoolean(DremioConfig.RBAC_ENABLED)) {
        return false;
    }
    // System user -> allow
    if (SystemUser.isSystemUserName(userName)) {
        return false;
    }
    // No RbacService -> allow (defensive)
    if (rbacService == null) {
        return false;
    }
    // Admin -> allow; non-admin -> deny
    if (!rbacService.isAdminMember(userName)) {
        logger.warn("RBAC: sys.privileges access denied for non-admin user '{}'", userName);
        return true;
    }
    return false;
}
```

Use `equalsIgnoreCase` for both root and leaf to handle case variation (Pitfall 1 from research).

Then wire `isRbacDeniedForSysPrivileges(key)` into every getTable() overload where `isRbacDeniedForVds` and `isRbacDeniedForPds` are called. The call sites are at approximately lines 290, 299, 312, 320, 332-334, and the bulkGetTables lambda at ~381. For each:

- `getTableNoResolve(NamespaceKey)` line ~290: change condition to `isRbacDeniedForVds(table, key) || isRbacDeniedForPds(table, key) || isRbacDeniedForSysPrivileges(key)`
- `getTableNoColumnCount(NamespaceKey)` line ~299: same pattern
- `getTable(NamespaceKey)` line ~312 (resolvedKey branch): same pattern with `resolvedKey`
- `getTable(NamespaceKey)` line ~320 (fallback): same pattern with `key`
- `getTable(CatalogEntityKey)` line ~332-334: same pattern with `namespaceKey`
- `bulkGetTables` lambda line ~381: add `|| isRbacDeniedForSysPrivileges(resolvedKey)`

Note: isRbacDeniedForSysPrivileges does NOT need the `table` parameter (unlike VDS/PDS which check table type). It only checks the namespace key path.

IMPORTANT: Do NOT modify SystemStoragePlugin.hasAccessPermission() or add grants for sys tables. The enforcement is admin-role-based, not grant-based.
