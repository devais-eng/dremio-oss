    1. **Update error message in validatePrivilege()** (around line 2837-2839):
       Change the throw statement from:
       ```java
       logger.warn("RBAC: Access denied for user '{}'", userName);
       throw UserException.validationError().message("Table '%s' not found", key).buildSilently();
       ```
       To (per locked decision — no GRANT hint, per research finding):
       ```java
       logger.warn("RBAC: Access denied for user '{}' — privilege {} on {}", userName, rbacPrivilege, objectPath);
       throw UserException.validationError()
           .message("Permission denied: %s privilege required on '%s'", rbacPrivilege, objectPath)
           .buildSilently();
       ```

    2. **Add DROP case to resolveRbacObjectType()** (around line 2848-2858):
       Add `case DROP:` to the fall-through group that returns "VDS". Place it between `ALTER` and `default`:
       ```java
       case ALTER:
       case DROP:
       default:
         return "VDS";
       ```

    3. **Add validateCreateViewPrivilege(NamespaceKey viewKey) method** after validatePrivilege():
       This method implements the container-scoped CREATE_VIEW check per locked decision. It follows the same 3-guard chain (flag OFF, system user, null service) as validatePrivilege(), but uses `viewKey.getParent().getSchemaPath()` as the object path:
       ```java
       @Override
       public void validateCreateViewPrivilege(NamespaceKey viewKey) {
           if (dremioConfig == null || !dremioConfig.getBoolean(DremioConfig.RBAC_ENABLED)) {
               return;
           }
           if (SystemUser.isSystemUserName(userName)) {
               return;
           }
           if (rbacService == null) {
               return;
           }
           String containerPath = viewKey.getParent().getSchemaPath();
           if (!rbacService.hasPrivilege(userName, "CREATE_VIEW", "VDS", containerPath)) {
               logger.warn("RBAC: Access denied for user '{}' — privilege CREATE_VIEW on {}", userName, containerPath);
               throw UserException.validationError()
                   .message("Permission denied: CREATE_VIEW privilege required on '%s'", containerPath)
                   .buildSilently();
           }
       }
       ```

    Then propagate the new method through the interface chain:

    4. **DatasetCatalog.java** — Add method signature after the existing `validatePrivilege` declaration (around line 255):
       ```java

       ```

    5. **SourceAccessChecker.java** — Add delegation method after the existing `validatePrivilege` override (around line 727):
       ```java
       @Override
       public void validateCreateViewPrivilege(NamespaceKey viewKey) {
           delegate.validateCreateViewPrivilege(viewKey);
       }
       ```

    6. **DelegatingCatalog.java** — Add delegation method after the existing `validatePrivilege` override (around line 558):
