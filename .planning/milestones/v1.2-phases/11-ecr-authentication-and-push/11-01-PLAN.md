Read the existing `.github/workflows/docker-ecr.yml` (has 5 steps: Checkout, Extract version, Set up Java, Build tarball, Verify tarball). Append 5 new steps after the existing "Verify tarball exists" step, in this exact order:

**Step 6 — Stage Docker context:**
```yaml
- name: Stage Docker context
  run: |
    mkdir docker-context
    cp distribution/server/target/dremio-community-*.tar.gz docker-context/dremio.tar.gz
    cp distribution/docker/Dockerfile docker-context/Dockerfile
```
This creates a clean build context directory with the tarball renamed to `dremio.tar.gz` (matching the Dockerfile's `ARG TARBALL_PATH=dremio.tar.gz` default) and the Dockerfile itself. The Dockerfile is copied into the context so that `build-push-action` can reference it with `file: docker-context/Dockerfile`.

**Step 7 — Set up Docker Buildx:**
```yaml
- name: Set up Docker Buildx
  uses: docker/setup-buildx-action@v3
```
Required by `docker/build-push-action@v6`. No inputs needed for single-platform linux/amd64 builds.

**Step 8 — Configure AWS credentials:**
```yaml
- name: Configure AWS credentials
  uses: aws-actions/configure-aws-credentials@v4
  with:
    aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
    aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
    aws-region: ${{ secrets.AWS_REGION }}
```
Uses `@v4` (not v1/v2). All three values come from GitHub Secrets — never hardcode credentials or region. This satisfies ECR-01.

**Step 9 — Login to Amazon ECR:**
```yaml
- name: Login to Amazon ECR
  id: login-ecr
  uses: aws-actions/amazon-ecr-login@v2
```
The `id: login-ecr` is critical — downstream steps reference `${{ steps.login-ecr.outputs.registry }}` to get the ECR registry URL dynamically (not hardcoded). This satisfies ECR-02.

**Step 10 — Build and push Docker image:**
```yaml
- name: Build and push Docker image
  uses: docker/build-push-action@v6
  with:
    context: docker-context
    file: docker-context/Dockerfile
    push: true
    tags: |
      ${{ steps.login-ecr.outputs.registry }}/${{ secrets.ECR_REPOSITORY }}:${{ steps.version.outputs.VERSION }}
      ${{ steps.login-ecr.outputs.registry }}/${{ secrets.ECR_REPOSITORY }}:latest
```
Uses `context: docker-context` (the staging directory, not repo root) so only the tarball and Dockerfile are sent to the Docker daemon. `file: docker-context/Dockerfile` points to the Dockerfile inside the context. Two tags are applied: versioned (e.g., `1.2`) from the version step output, and `latest`. The registry URL comes from the ECR login step output (not hardcoded). This satisfies ECR-03 and ECR-04.

**Important — do NOT:**
- Hardcode any AWS account ID, region, or ECR registry URL in the workflow file
- Add `build-args` for TARBALL_PATH — the Dockerfile default `dremio.tar.gz` matches the staged filename
- Add `platforms` to build-push-action — single platform (runner default) is correct
- Change any of the existing 5 steps — only append after them
