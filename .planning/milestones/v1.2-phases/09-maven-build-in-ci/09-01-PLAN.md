  <action>
Create `.github/workflows/docker-ecr.yml` with the following structure:

**Workflow name:** `Build and Push to ECR`

**Trigger (TRIG-01):**
```yaml
on:
  push:
    tags:
      - 'v*'
```
This MUST be the only trigger. Do NOT add `workflow_dispatch`, `pull_request`, or branch push triggers.

**Permissions:** Set `contents: read` at workflow level (least privilege).

**Job:** Single job named `build` running on `ubuntu-latest`.

**Steps (in exact order):**

1. **Checkout** -- `actions/checkout@v4`. No special options needed.

2. **Extract version (TRIG-02, TRIG-03):**
```yaml
- name: Extract version from tag
  id: version
  run: echo "VERSION=${GITHUB_REF_NAME#v}" >> "$GITHUB_OUTPUT"
```
This strips the `v` prefix: `v1.2.0` becomes `1.2.0`. The output is referenced later as `${{ steps.version.outputs.VERSION }}`.

3. **Setup Java (BILD-01, BILD-02):**
```yaml
- name: Set up Java 21
  uses: actions/setup-java@v5
  with:
    java-version: '21'
    distribution: 'temurin'
    cache: 'maven'
```
Java 21 satisfies the Maven enforcer `[21,22)` range. The `cache: 'maven'` option auto-caches `~/.m2/repository` keyed on `**/pom.xml` hashes.

4. **Maven build (BILD-03, BILD-04):**
```yaml
- name: Build distribution tarball
  run: ./mvnw package -DskipTests -Pdremio.no-lint -pl distribution/server -am -Drevision=${{ steps.version.outputs.VERSION }}
```
- `-DskipTests`: Skip test execution (CI build only)
- `-Pdremio.no-lint`: Skip lint checks (Checkstyle, etc.)
- `-pl distribution/server -am`: Build only the distribution/server module and its dependencies
- `-Drevision={version}`: Set the Maven revision property to the extracted version

5. **Post-build verification (BILD-04 confirmation):**
```yaml
- name: Verify tarball exists
  run: ls -lh distribution/server/target/dremio-community-*.tar.gz
```
This step will fail the workflow if no tarball was produced, providing an explicit signal rather than a silent absence.

**Important constraints:**
- Do NOT add any Docker or ECR steps -- those are Phase 10 and Phase 11
- Do NOT add environment variables for AWS -- not needed yet
- Do NOT add `concurrency` settings -- keep it simple for now
- The workflow file MUST be valid YAML with proper indentation (2-space indent throughout)
