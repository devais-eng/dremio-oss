     - Add imports: `javax.ws.rs.core.SecurityContext`, `javax.ws.rs.core.Context`, `javax.annotation.Nullable`, `com.dremio.exec.rbac.RbacService`, `com.dremio.config.DremioConfig`, `com.dremio.service.namespace.NamespaceService`, `com.dremio.service.namespace.proto.EntityId`, `com.dremio.service.namespace.proto.NameSpaceContainer`, `com.dremio.common.exceptions.UserException`, `com.dremio.catalog.model.VersionedDatasetId`.

  2. Add a private helper method `enforceAlterPrivilege(String id)` following the established Phase 21 pattern:
     ```java
     private void enforceAlterPrivilege(String id) {
       if (rbacService == null || dremioConfig == null
           || !dremioConfig.getBoolean(DremioConfig.RBAC_ENABLED)) {
         return;
       }
       String userName = securityContext.getUserPrincipal().getName();
       if (rbacService.isAdminMember(userName)) {
         return;
       }
       // Versioned entities (Nessie) -- skip RBAC for now (no namespace entry)
       if (VersionedDatasetId.tryParse(id) != null) {
         return;
       }
       Optional<NameSpaceContainer> container =
           namespaceService.getEntityById(new EntityId(id));
       if (container.isEmpty()) {
         return; // entity not found -- let downstream throw
       }
       NameSpaceContainer entity = container.get();
       // Determine object type and path for privilege check
       String objectPath = String.join(".", entity.getFullPathList());
       String objectType;
       switch (entity.getType()) {
         case DATASET:
           objectType = entity.getDataset().getType()
               == com.dremio.service.namespace.dataset.proto.DatasetType.VIRTUAL_DATASET
               ? "VDS" : "PDS";
           break;
         case FOLDER:
           // Folder ALTER requires privilege on parent space
           objectType = "SPACE";
           objectPath = entity.getFullPathList().get(0);
           break;
         case SPACE:
           objectType = "SPACE";
           break;
         case SOURCE:
           // Source tags/wiki mutation is admin-only
           throw UserException.validationError()
               .message("Permission denied: only administrators can modify source metadata.")
               .buildSilently();
         default:
           return; // HOME and other types -- allow
       }
       if (!rbacService.hasPrivilege(userName, "ALTER", objectType, objectPath)) {
         throw UserException.validationError()
             .message("Permission denied: ALTER privilege required on '%s'.", objectPath)
             .buildSilently();
       }
     }
     ```

  3. Call `enforceAlterPrivilege(id)` at the top of `setTagsForEntity()` and `setWikiForEntity()`, before any delegation to collaborationHelper.

  4. Do NOT add guards to the GET methods (getTagsForEntity, getWikiForEntity) -- reading tags/wiki is allowed for any authenticated user.
