<objective>
Fix DACSecurityContext.isUserInRole() to check actual admin role membership via RbacService, making all @RolesAllowed("admin") annotations on JAX-RS endpoints effective.

Purpose: UAT retest revealed isUserInRole() unconditionally returns true, so @RolesAllowed("admin") on UserResource.createUser() and updateUser() (added in Phase 21) has no effect. This is the root cause of API-01 remaining open. Fixing the security context also future-proofs any endpoint that uses @RolesAllowed("admin").

Output: Fixed DACSecurityContext with RBAC-aware admin check, updated DACAuthFilter injection, all existing call sites updated for new constructor signature, unit tests for isUserInRole() logic, integration tests for User API 403 enforcement.
</objective>
