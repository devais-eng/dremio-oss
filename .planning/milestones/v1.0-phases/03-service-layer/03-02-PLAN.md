**Test setup (follow Phase 2 pattern exactly):**
```java
private LocalKVStoreProvider kvStoreProvider;
private RoleStore roleStore;
private GrantStore grantStore;
private MembershipStore membershipStore;
private RbacService rbacService;

@Before
public void setUp() throws Exception {
  kvStoreProvider = new LocalKVStoreProvider(DremioTest.CLASSPATH_SCAN_RESULT, null, true, false);
  kvStoreProvider.start();
  roleStore = new RoleStore(() -> kvStoreProvider);
  grantStore = new GrantStore(() -> kvStoreProvider);
  membershipStore = new MembershipStore(() -> kvStoreProvider);
  rbacService = new RbacService(roleStore, grantStore, membershipStore);
}

@After
public void tearDown() throws Exception {
  kvStoreProvider.close();
}
```

**Required test methods (approximately 15-18 tests):**

**Success Criteria 1 -- Deny by default (ENFC-04/ENFC-05):**
1. `testHasPrivilege_denyByDefault`: Create no grants, no memberships. Call `rbacService.hasPrivilege("alice", "SELECT", "VDS", "schemas.my_view")`. Assert returns false.

**Success Criteria 2 -- ADMIN bypass (ROLE-05, ENFC-04):**
2. `testHasPrivilege_adminBypass`: Create ADMIN membership for alice via `rbacService.assignBootstrapAdmin("alice")`. Call `hasPrivilege("alice", "SELECT", "VDS", "schemas.my_view")` without any grants. Assert returns true.

**Success Criteria 3 -- PUBLIC implicit membership (ROLE-06, ENFC-05):**
3. `testHasPrivilege_publicGrant`: Grant SELECT on "VDS"/"schemas.my_view" to PUBLIC_ROLE_ID via `rbacService.grantPrivilege(RbacService.PUBLIC_ROLE_ID, "VDS", "schemas.my_view", "SELECT", "admin")`. Call `hasPrivilege("bob", "SELECT", "VDS", "schemas.my_view")` where bob has NO explicit memberships. Assert returns true.

**Success Criteria 4 -- Bootstrap ADMIN assignment (BOOT-01):**
4. `testAssignBootstrapAdmin`: Call `rbacService.assignBootstrapAdmin("alice")`. Then verify `rbacService.hasPrivilege("alice", "SELECT", "VDS", "anything")` returns true (ADMIN bypass).
5. `testAssignBootstrapAdmin_duplicate`: Call `assignBootstrapAdmin("alice")` twice. Second call should throw `RbacEntityAlreadyExistsException`.

**Success Criteria 5 -- AccessControlListingManager (ROLE-05, ROLE-06):**
6. `testGetRoleInfo_builtInRoles`: With no user-created roles, call `getRoleInfo()`. Assert it contains exactly 2 entries. Assert one has role_id=ADMIN_ROLE_ID, role_type="SYSTEM". Assert one has role_id=PUBLIC_ROLE_ID, role_type="SYSTEM".
7. `testGetRoleInfo_withUserRoles`: Create a role "analyst" via `rbacService.createRole("analyst", "Analyst", "admin")`. Call `getRoleInfo()`. Assert 3 entries: ADMIN (SYSTEM), PUBLIC (SYSTEM), analyst (USER type, created_by="admin").
8. `testGetPrivilegeInfo`: Grant SELECT on VDS to role "analyst" (create role first). Call `getPrivilegeInfo()`. Assert 1 entry with grantee_type="ROLE", grantee="analyst", object_type="VDS", privilege="SELECT".
9. `testGetMembershipInfo_excludesPublic`: Add alice to "analyst" role (create role first). Call `getMembershipInfo()`. Assert 1 entry with role_name="analyst", member_name="alice", member_type="USER". Assert no entry with role_name="PUBLIC" (per locked decision).

**Privilege resolution detail tests:**
10. `testHasPrivilege_explicitRoleGrant`: Create role "analyst", add alice to analyst, grant SELECT on VDS to analyst. Assert `hasPrivilege("alice", "SELECT", "VDS", "schemas.my_view")` returns true.
11. `testHasPrivilege_wrongPrivilege`: Create role "analyst", add alice to analyst, grant SELECT on VDS to analyst. Assert `hasPrivilege("alice", "EXECUTE", "VDS", "schemas.my_view")` returns false.
12. `testHasPrivilege_multipleRolesOrLogic`: Create roles "analyst" and "viewer", add alice to both, grant SELECT on different paths. Assert alice gets privilege from either role.

**Immutability guard tests:**
13. `testCreateRole_rejectsAdmin`: `assertThatThrownBy(() -> rbacService.createRole("ADMIN", "Admin", "anyone")).isInstanceOf(IllegalArgumentException.class)`.
14. `testCreateRole_rejectsPublic`: `assertThatThrownBy(() -> rbacService.createRole("PUBLIC", "Public", "anyone")).isInstanceOf(IllegalArgumentException.class)`.
15. `testDeleteRole_rejectsAdmin`: `assertThatThrownBy(() -> rbacService.deleteRole("ADMIN")).isInstanceOf(IllegalArgumentException.class)`.
16. `testDeleteRole_rejectsPublic`: `assertThatThrownBy(() -> rbacService.deleteRole("PUBLIC")).isInstanceOf(IllegalArgumentException.class)`.
17. `testAddMembership_rejectsPublic`: `assertThatThrownBy(() -> rbacService.addMembership("alice", "PUBLIC", "admin")).isInstanceOf(IllegalArgumentException.class)`.
18. `testRemoveMembership_rejectsAdmin`: `assertThatThrownBy(() -> rbacService.removeMembership("alice", "ADMIN")).isInstanceOf(IllegalArgumentException.class)`.
19. `testRemoveMembership_rejectsPublic`: `assertThatThrownBy(() -> rbacService.removeMembership("alice", "PUBLIC")).isInstanceOf(IllegalArgumentException.class)`.

**Fail-fast test:**
20. `testValidateAdminMembersExist_throwsWhenEmpty`: Call `validateAdminMembersExist()` with no ADMIN members. Assert `IllegalStateException` with message containing "ADMIN role has no members".
21. `testValidateAdminMembersExist_passesWithMember`: Call `assignBootstrapAdmin("alice")` then `validateAdminMembersExist()`. Should not throw.

**Role existence validation tests:**
22. `testGrantPrivilege_rejectsNonExistentRole`: `assertThatThrownBy(() -> rbacService.grantPrivilege("nonexistent", "VDS", "path", "SELECT", "admin")).isInstanceOf(RbacEntityNotFoundException.class)`.
23. `testAddMembership_rejectsNonExistentRole`: `assertThatThrownBy(() -> rbacService.addMembership("alice", "nonexistent", "admin")).isInstanceOf(RbacEntityNotFoundException.class)`.
24. `testAddMembership_allowsAdminRole`: `rbacService.addMembership("alice", "ADMIN", "admin")` should NOT throw (ADMIN is a valid built-in role).
