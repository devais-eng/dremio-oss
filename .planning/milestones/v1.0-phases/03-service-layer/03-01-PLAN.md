  <action>
Create `com.dremio.exec.rbac.RbacService` that implements `com.dremio.exec.store.sys.accesscontrol.AccessControlListingManager`.

**Class structure:**

1. **Constants:**
   - `public static final String ADMIN_ROLE_ID = "ADMIN";`
   - `public static final String PUBLIC_ROLE_ID = "PUBLIC";`

2. **Constructor dependencies (all final fields):**
   - `RoleStore roleStore`
   - `GrantStore grantStore`
   - `MembershipStore membershipStore`
   - Constructor takes all three stores. No `@Inject` annotation (Phase 4 handles DI wiring).

3. **Service lifecycle (from `Service` interface via `AccessControlListingManager extends Service`):**
   - `start()`: no-op (fail-fast validation is called separately by startup code in Phase 4)
   - `close()`: no-op (stores are managed by KVStoreProvider lifecycle)

4. **Privilege resolution -- `hasPrivilege(String userName, String privilege, String objectType, String objectPath)` returns `boolean`:**
   - Per locked decision, resolution order is: ADMIN check -> collect roles + PUBLIC -> check grants
   - Step 1: Check if user is ADMIN member. Call `membershipStore.get(RbacConfig.membershipKey(userName, ADMIN_ROLE_ID))`. If not null, return true immediately (short-circuit).
   - Step 2: Collect user's explicit role IDs. Call `membershipStore.listByUser(userName)`, stream `.map(Membership::getRoleId)` into a `List<String>`. Then add `PUBLIC_ROLE_ID` to the list (implicit PUBLIC membership -- per locked decision, this is in the same pass, not a fallback).
   - Step 3: For each roleId in the collected list, build grant key via `RbacConfig.grantKey(roleId, objectType, objectPath, privilege)` and call `grantStore.get(grantKey)`. If any returns non-null, return true (OR logic).
   - If no grant found across all roles, return false (deny-by-default).
   - Validate inputs with `Preconditions.checkArgument(!Strings.isNullOrEmpty(...))` for all four parameters.

5. **Role lifecycle:**
   - `createRole(String roleId, String roleName, String createdBy)`: Guard against ADMIN_ROLE_ID and PUBLIC_ROLE_ID with `Preconditions.checkArgument`. Build proto `Role.newBuilder().setRoleId(roleId).setRoleName(roleName).setCreatedBy(createdBy).setCreatedAt(System.currentTimeMillis()).build()`. Delegate to `roleStore.create(roleId, role)`.
   - `deleteRole(String roleId)` throws `RbacEntityNotFoundException`: Guard against ADMIN_ROLE_ID and PUBLIC_ROLE_ID with `Preconditions.checkArgument("Cannot drop built-in role: " + roleId)`. Delegate to `roleStore.delete(roleId, grantStore, membershipStore)` (cascade).

6. **Membership lifecycle:**
   - `addMembership(String userName, String roleId, String grantedBy)`: Guard against PUBLIC_ROLE_ID with `Preconditions.checkArgument("Cannot explicitly add membership to built-in role: PUBLIC")`. For ADMIN_ROLE_ID, skip role existence check (synthetic). For other roles, check `roleStore.get(roleId) != null`, else throw `RbacEntityNotFoundException("Role not found: " + roleId)`. Build proto `Membership.newBuilder().setUserName(userName).setRoleId(roleId).setGrantedBy(grantedBy).setGrantedAt(System.currentTimeMillis()).build()`. Delegate to `membershipStore.add(RbacConfig.membershipKey(userName, roleId), membership)`.
   - `removeMembership(String userName, String roleId)` throws `RbacEntityNotFoundException`: Guard against ADMIN_ROLE_ID with `Preconditions.checkArgument("Cannot remove membership from built-in role: ADMIN")`. Guard against PUBLIC_ROLE_ID with `Preconditions.checkArgument("Cannot remove membership from built-in role: PUBLIC")`. Delegate to `membershipStore.remove(RbacConfig.membershipKey(userName, roleId))`.

7. **Grant lifecycle:**
   - `grantPrivilege(String roleId, String objectType, String objectPath, String privilege, String grantedBy)`: For built-in roles (ADMIN_ROLE_ID, PUBLIC_ROLE_ID), skip role existence check. For others, check `roleStore.get(roleId) != null`, else throw `RbacEntityNotFoundException("Role not found: " + roleId)`. Build proto `Grant.newBuilder().setRoleId(roleId).setObjectType(objectType).setObjectPath(objectPath).setPrivilege(privilege).setGrantedBy(grantedBy).setGrantedAt(System.currentTimeMillis()).build()`. Delegate to `grantStore.grant(RbacConfig.grantKey(roleId, objectType, objectPath, privilege), grant)`.
   - `revokePrivilege(String roleId, String objectType, String objectPath, String privilege)` throws `RbacEntityNotFoundException`: Delegate to `grantStore.revoke(RbacConfig.grantKey(roleId, objectType, objectPath, privilege))`.

8. **Bootstrap:**
   - `assignBootstrapAdmin(String userName)`: Creates ADMIN membership for the given user. Build `Membership.newBuilder().setUserName(userName).setRoleId(ADMIN_ROLE_ID).setGrantedBy("SYSTEM").setGrantedAt(System.currentTimeMillis()).build()`. Call `membershipStore.add(RbacConfig.membershipKey(userName, ADMIN_ROLE_ID), membership)`. This may throw `RbacEntityAlreadyExistsException` if called again (idempotency guard in callers).

9. **Fail-fast validation:**
   - `validateAdminMembersExist()`: Call `membershipStore.listByRole(ADMIN_ROLE_ID)`. If list is empty, throw `IllegalStateException` with message: "RBAC is enabled (services.rbac.enabled=true) but the ADMIN role has no members. Either assign a user to the ADMIN role or set services.rbac.enabled=false in dremio.conf. Coordinator will not start without an ADMIN member when RBAC is enabled."

10. **AccessControlListingManager implementation:**
    - `getRoleInfo()`: Create `ArrayList<SysTableRoleInfo>`. Add two synthetic entries: `new SysTableRoleInfo(ADMIN_ROLE_ID, ADMIN_ROLE_ID, "SYSTEM", null, null, "SYSTEM")` and `new SysTableRoleInfo(PUBLIC_ROLE_ID, PUBLIC_ROLE_ID, "SYSTEM", null, null, "SYSTEM")`. Then iterate `roleStore.listAll()`, for each Role: `new SysTableRoleInfo(role.getRoleId(), role.getRoleName(), "USER", null, null, role.getCreatedBy())`. Return the list.
    - `getPrivilegeInfo()`: Create `ArrayList<SysTablePrivilegeInfo>`. Iterate `grantStore.listAll()`, for each Grant: `new SysTablePrivilegeInfo("ROLE", grant.getRoleId(), grant.getObjectType(), grant.getObjectPath(), grant.getPrivilege())`. Return the list.
    - `getMembershipInfo()`: Create `ArrayList<SysTableMembershipInfo>`. Iterate `membershipStore.listAll()`, for each Membership: `new SysTableMembershipInfo(membership.getRoleId(), membership.getUserName(), "USER")`. Return the list. Per locked decision, PUBLIC implicit memberships are NOT included -- only explicit memberships from the store.
