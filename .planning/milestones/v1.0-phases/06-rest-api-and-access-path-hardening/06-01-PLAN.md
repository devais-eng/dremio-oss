**Private helper methods:**

```java
private void requireRbacEnabled() {
  if (!dremioConfig.getBoolean(DremioConfig.RBAC_ENABLED)) {
    throw UserException.unsupportedError()
        .message("RBAC is not enabled. Set services.rbac.enabled=true in dremio.conf")
        .buildSilently();
  }
}

private void requireAdmin() {
  String userName = securityContext.getUserPrincipal().getName();
  if (!rbacService.isAdminMember(userName)) {
    throw UserException.permissionError()
        .message("Only ADMIN role members can access RBAC management endpoints")
        .buildSilently();
  }
}

private String getUserName() {
  return securityContext.getUserPrincipal().getName();
}
```

8. `@POST @Path("/grants") grantPrivilege(GrantRequest request)` -- Calls `rbacService.grantPrivilege(request.getRoleId(), request.getObjectType(), request.getObjectPath(), request.getPrivilege(), getUserName())`. Catch `RbacEntityNotFoundException` -> `NotFoundException`. Catch `RbacEntityAlreadyExistsException` -> `WebApplicationException(CONFLICT)`. Returns the created `RbacGrant`. (REST-08)

9. `@DELETE @Path("/grants") revokePrivilege(@QueryParam("roleId") String roleId, @QueryParam("objectType") String objectType, @QueryParam("objectPath") String objectPath, @QueryParam("privilege") String privilege)` -- Validates all 4 params non-null (else `BadRequestException`). Calls `rbacService.revokePrivilege(roleId, objectType, objectPath, privilege)`. Catch `RbacEntityNotFoundException` -> `NotFoundException`. Returns `Response.noContent().build()`. (REST-09)

**Important notes:**
- Do NOT rely on @RolesAllowed("admin") for actual access control -- it's a no-op (DACSecurityContext.isUserInRole() always returns true).
- Use `UserException.permissionError()` for admin check failures and `UserException.unsupportedError()` for RBAC-disabled errors. These are handled by Dremio's DACExceptionMapperFeature.
- For RbacEntityNotFoundException and RbacEntityAlreadyExistsException, catch and re-throw as JAX-RS NotFoundException / WebApplicationException(409) since these custom exceptions are in sabot/kernel and don't have automatic JAX-RS mapping.
- DELETE /rbac/grants uses query parameters (NOT request body) for the 4 grant key components, following the pattern of DELETE /catalog/{id}?tag=... in CatalogResource.
