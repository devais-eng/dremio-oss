## Cross-Phase Integration

### Verified Wiring (18 connections)

1. **Phase 28 → Phase 21/22**: `DACSecurityContext.isUserInRole()` → `rbacService.isAdminMember()` makes all `@RolesAllowed("admin")` annotations effective
2. **Phase 23 → UI**: Login response `admin` flag → localStorage → navSections, RouteMixin, UsersView, DatasetMenuMixin, AllSpacesView, HeaderButtonsMixin
3. **Phase 23 → UI**: SessionPermissions (`canCreateSource`, `canCreateUser`) → localStorage → AddSourceButton, SpacesSection
4. **Phase 22 → Runtime**: Programmatic `rbacService.hasPrivilege()` guards on Collaboration, Scripts, Folders, Reflections (independent of `@RolesAllowed`)
5. **Phase 27 → Phase 21**: ALTER check moved before `renameDataset()` in TOCTOU-vulnerable VDS update path
6. **Phase 29 → Phase 25**: CREATE_VIEW key alignment (`objectType=SPACE`, `path=getRoot()`) matches grant storage format
7. **Phase 25/29 dual-path LOGIC-01**: v2 SpaceResource + v3 CatalogServiceHelper both filter independently
8. **Phase 25/29 dual-path LOGIC-02**: SystemTableScanCreator + SysFlightScanCreator both filter; CatalogImpl gate allows non-admin access

### Acknowledged Limitation

**UI-04 entity permissions over-restriction**: `DatasetMenuMixin.jsx` gates on `entity.get("permissions")?.get("canAlter")` which is undefined in OSS backend responses. Result: non-admin menu items are hidden regardless of explicit grants (secure-by-default). This satisfies the security requirement but does not yet enable selective visibility. Out of v1.4 scope.
