## Notable Findings

### Finding 1: DROP VDS requires SELECT + DROP (undocumented)
`DropViewHandler` calls `validatePrivilege(DROP)` then `getTableNoColumnCount()` which applies SELECT check. User with DROP-only gets misleading "Unknown view" error. Documented in TestRbacIntegration. **Affects:** LIFE-02 UX.

### Finding 2: `getTable(String datasetId)` PDS gap
Versioned-dataset-ID lookup path at CatalogImpl.java:1214 has no `isRbacDeniedForPds` check. Intentional TODO — path not reachable by standard PDS queries. **Affects:** PDS-02 (partial, bounded scope).

### Finding 3: Container visibility E2E coverage gap
Integration tests verify container visibility via SQL (query denied), not REST API listings (endpoint returns filtered list). `filterByRbacVisibility()` has unit tests but no integration assertion. **Affects:** CONT-01, CONT-02 test coverage only.

### Finding 4: Source creation metadata leak (discovered during demo)
`SourceService.createSource()` checks existence before RBAC. Non-admin user trying to add an existing source sees "already exists" instead of "permission denied". Not mapped to any v1.2 requirement. **New issue for future milestone.**
