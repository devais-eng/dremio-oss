## E2E Flow (1/1)

### v* Tag Push → ECR Image

```
git push tag v1.2.0
  → on: push: tags: ['v*']               [TRIG-01]
  → ${GITHUB_REF_NAME#v} → "1.2.0"       [TRIG-02]
  → setup-java@v5 Java 21 + Maven cache  [BILD-01, BILD-02]
  → ./mvnw package -Drevision=1.2.0      [BILD-03, TRIG-03]
  → ls dremio-community-1.2.0.tar.gz     [BILD-04]
  → mkdir docker-context; cp + rename     [DOCK-04]
  → setup-buildx-action@v3
  → configure-aws-credentials@v4         [ECR-01]
  → amazon-ecr-login@v2                  [ECR-02]
  → build-push-action@v6                 [DOCK-01, DOCK-02, DOCK-03]
    → push: true
    → {registry}/{repo}:1.2.0            [ECR-03, TRIG-03]
    → {registry}/{repo}:latest           [ECR-04]
```

## Observations (non-blocking)

1. **Implicit Maven profile dependency** (low) — The tarball glob `dremio-community-*.tar.gz` depends on the `community-build` Maven profile being auto-activated (no `-Ddremio.oss-only=true`). Adding that flag would change the tarball name to `dremio-oss-*` and break the glob. Documented here for awareness. [BILD-04]
