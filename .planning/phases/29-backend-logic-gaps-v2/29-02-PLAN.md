The KV key mismatch means the privilege lookup always misses, blocking non-admin view creation even when the grant exists.

Output: One-line objectType change ("VDS" to "SPACE") and one-line path change (getParent().getSchemaPath() to getRoot()) in validateCreateViewPrivilege(). Existing tests updated to assert the correct post-fix behavior.
</objective>
