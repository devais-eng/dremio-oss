Create a helper to submit SQL as a specific user and wait for completion (returning the job result or throwing on failure):

```java
private static void runSqlAsUser(String sql, String username) {
    submitJobAndWaitUntilCompletion(
        JobRequest.newBuilder()
            .setSqlQuery(new SqlQuery(sql, username))
            .build());
}
```

Create a helper to submit SQL and expect failure, returning the error message:

```java
private static String runSqlExpectingFailure(String sql, String username) {
    try {
        submitJobAndWaitUntilCompletion(
            JobRequest.newBuilder()
                .setSqlQuery(new SqlQuery(sql, username))
                .build());
        fail("Expected query to fail: " + sql);
        return null; // unreachable
    } catch (Exception e) {
        return e.getMessage();
    }
}
```

Note: The `submitJobAndWaitUntilCompletion` method is a static method from `BaseTestServer` that submits a `JobRequest` and blocks until the job completes or fails. If the job fails, it throws an exception with the error message from the query engine. Use `JobRequest.newBuilder().setSqlQuery(new SqlQuery(sql, username)).build()` to construct the request.
