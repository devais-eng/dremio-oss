<objective>
Wire Keycloak JWT authentication into Arrow Flight SQL credential validators so that Flight SQL clients (JDBC/ODBC) can authenticate with Keycloak access tokens, with JIT provisioning and role sync on first login.

Purpose: Completes v1.5 Keycloak integration by extending the same eyJ-dispatch pattern from DACAuthFilter (REST API) into Arrow Flight's auth2 and legacy authentication modes.
Output: Modified DremioFlightAuthProviderImpl, DremioCredentialValidator, DremioBearerTokenAuthenticator, DremioFlightServerBasicAuthValidator, DACDaemonModule wiring, and unit tests.
