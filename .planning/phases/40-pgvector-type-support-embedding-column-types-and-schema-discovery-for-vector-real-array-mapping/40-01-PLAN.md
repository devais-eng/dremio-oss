<objective>
Map PostgreSQL pgvector `vector(N)` columns to `LIST<FLOAT>` (Arrow `ListVector` with a `Float4` child) in schema discovery, and add a `ListVector` writing branch in `JdbcRecordReader` that parses the pgjdbc text format `[x,y,z]` into individual floats. Upgrade the test container image to `pgvector/pgvector:pg16` and add integration tests confirming schema shape and value roundtrip.

Purpose: Phase 41 will register distance functions as `l2_distance(LIST<FLOAT>, LIST<FLOAT>) → FLOAT`. If embeddings are VARCHAR the functions cannot execute in-engine when pushdown does not happen (cross-source joins, non-whitelisted expressions). LIST<FLOAT> means the functions always work — pushdown is an optimization, not a requirement.

Output: Three source files modified (PostgresSchemaFetcher, JdbcRecordReader, DremioPostgresContainer) + one new test class (TestPgvectorTypeMapping).
</objective>

2. Override `getTableSchema(String schemaName, String tableName)` to intercept the `ArrowType.List.INSTANCE` sentinel and construct the proper `Field` with a `Float4` child. The base class creates `new Field(columnName, fieldType, null)` — for `List` we must pass a non-null children list. Call `super.getTableSchema()` is NOT viable because we need to intercept per-column. Instead, duplicate the loop from `JdbcSchemaFetcher.getTableSchema()` with one extra branch:

```java
@Override
public BatchSchema getTableSchema(String schemaName, String tableName) throws SQLException {
    List<Field> fields = new ArrayList<>();
    try (Connection conn = getPool().getConnection()) {
        DatabaseMetaData meta = conn.getMetaData();
        try (ResultSet rs = meta.getColumns(null, schemaName, tableName, "%")) {
            while (rs.next()) {
                String columnName = rs.getString("COLUMN_NAME");
                int jdbcType = rs.getInt("DATA_TYPE");
                String typeName = rs.getString("TYPE_NAME");
                int precision = rs.getInt("COLUMN_SIZE");
                int scale = rs.getInt("DECIMAL_DIGITS");
                boolean nullable = "YES".equalsIgnoreCase(rs.getString("IS_NULLABLE"));

                ArrowType arrowType = mapJdbcType(jdbcType, typeName, precision, scale);

                Field field;
                if (arrowType == ArrowType.List.INSTANCE) {
                    // pgvector: build LIST<FLOAT4> with the required child field
                    Field float4Child = new Field(
                        "$data$",
                        FieldType.nullable(new ArrowType.FloatingPoint(FloatingPointPrecision.SINGLE)),
                        null);
                    field = new Field(
                        columnName,
                        new FieldType(nullable, ArrowType.List.INSTANCE, null),
                        java.util.Collections.singletonList(float4Child));
                } else {
                    field = new Field(columnName, new FieldType(nullable, arrowType, null), null);
                }
                fields.add(field);
            }
        }
    }
    return new BatchSchema(fields);
}
```

`getPool()` — the base class field is `pool` (private). Expose it via a protected getter OR change the field visibility. Check `JdbcSchemaFetcher`: the field `pool` is `private final`. The cleanest approach without modifying the base class: add a protected getter `getPool()` to `JdbcSchemaFetcher` and use it from the override. Alternatively, if the pool is passed to the constructor and stored locally, store a second reference in `PostgresSchemaFetcher`. Either way: do NOT change the base-class field to public; use the getter approach.

In `writeValue()`, insert a new `else if` branch BEFORE the final `else` fallback, after the `IntervalDayVector` branch:

```java
} else if (vec instanceof ListVector) {
    String val = rs.getString(colPosition);
    if (!rs.wasNull() && val != null) {
        ListVector lv = (ListVector) vec;
        // Parse pgjdbc vector text format: "[x1,x2,...,xN]"
        String trimmed = val.trim();
        if (trimmed.startsWith("[") && trimmed.endsWith("]")) {
            trimmed = trimmed.substring(1, trimmed.length() - 1);
        }
        String[] parts = trimmed.isEmpty() ? new String[0] : trimmed.split(",");
        // ListVector child must be a Float4Vector
        Float4Vector childVec = (Float4Vector) lv.getDataVector();
        int startOffset = lv.getOffsetBuffer().getInt((long) index * 4);
        for (int i = 0; i < parts.length; i++) {
            float f = Float.parseFloat(parts[i].trim());
            childVec.setSafe(startOffset + i, f);
        }
        lv.getOffsetBuffer().setInt((long) (index + 1) * 4, startOffset + parts.length);
        lv.setNotNull(index);
    }
    // If null: ListVector slot stays null (validity bit 0 by default from allocateNew)
}
```

Note: `ListVector.setSafe()` does not exist for the list-of-values pattern. The correct low-level write is: set offset start (already set by `allocateNew`), write child values, set offset end, call `setNotNull`. The child vector capacity is managed by `setSafe()` on the child. This is the standard Arrow Java ListVector write pattern.
