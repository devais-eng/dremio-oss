**Creating SqlNode mocks:**

The SqlNode constructors take SqlParserPos and SqlIdentifier/SqlLiteral args. For constructing test nodes:

```java
// SqlIdentifier for simple names
private SqlIdentifier id(String name) {
    return new SqlIdentifier(name, SqlParserPos.ZERO);
}

// SqlIdentifier for compound paths (e.g., myspace.myview)
private SqlIdentifier compoundId(String... parts) {
    return new SqlIdentifier(Arrays.asList(parts), SqlParserPos.ZERO);
}

// SqlLiteral for enum values
private <E extends Enum<E>> SqlLiteral literal(E value) {
    return SqlLiteral.createSymbol(value, SqlParserPos.ZERO);
}

// SqlNodeList for privilege lists
private SqlNodeList privList(SqlGrant.Privilege... privs) {
    SqlNodeList list = new SqlNodeList(SqlParserPos.ZERO);
    for (SqlGrant.Privilege p : privs) {
        list.add(literal(p));
    }
    return list;
}
```
