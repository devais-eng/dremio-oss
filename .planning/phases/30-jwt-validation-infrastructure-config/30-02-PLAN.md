From 30-RESEARCH.md -- OidcTokenValidator pattern:
```java
// Nimbus JWKSourceBuilder handles caching (5 min TTL), rate limiting (30s),
// and automatic refresh on unknown kid -- no custom cache logic needed.
JWKSource<SecurityContext> keySource = JWKSourceBuilder
    .create(new URL(jwksUri))
    .retrying(true)
    .build();

ConfigurableJWTProcessor<SecurityContext> processor = new DefaultJWTProcessor<>();
processor.setJWSKeySelector(
    new JWSVerificationKeySelector<>(JWSAlgorithm.RS256, keySource));
processor.setJWTClaimsSetVerifier(new DefaultJWTClaimsVerifier<>(
    new JWTClaimsSet.Builder()
        .issuer(expectedIssuer)
        .audience(expectedAudience)
        .build(),
    new HashSet<>(Arrays.asList("sub", "exp", "iat", "iss", "aud"))));
```

    - testKeyRotation: Start with key1 in JWKS. Validate a token signed by key1 (succeeds). Update JWKS endpoint to serve key2 (different kid). Sign a new token with key2. Validate it -- should succeed after JWKSourceBuilder auto-refreshes on unknown kid.
    - testMalformedToken: Pass "not-a-jwt" string. Assert ParseException (or wrapped IllegalArgumentException) is thrown.
