Rewrite `getPhysicalOperator(PhysicalPlanCreator creator)` in `JdbcJoinScanPrel.java` to use `SqlDialect` directly instead of `SqlBuilder.buildJoinSql()`. Keep ALL existing fields, constructors, accessors, and Prel contract methods unchanged.

**Implementation:**

1. Resolve dialect (not SqlBuilder):
   ```java
   StoragePlugin rawPlugin = creator.getContext().getCatalogService().getSource(pluginId.getName());
   SqlDialect dialect = (rawPlugin instanceof JdbcStoragePlugin)
       ? ((JdbcStoragePlugin) rawPlugin).createDialect()
       : PostgresqlSqlDialect.DEFAULT;
   ```

2. Build JOIN SQL using dialect:
   - Use `dialect.quoteIdentifier()` for all schema, table, column, and alias identifiers.
   - Determine AS keyword usage from dialect: `boolean useAs = !(dialect instanceof OracleSqlDialect)`. This replaces the entire OracleSqlBuilder.buildJoinSql() override.
   - Build SELECT list: iterate leftColumns then rightColumns, each as `quotedAlias.quotedColName`. Add `AS quotedCalciteName` (or space + `quotedCalciteName` for Oracle) when the Calcite output field name differs from the original column name (self-join dedup).
   - Build FROM clause: `FROM quotedLeftSchema.quotedLeftTable [AS] quotedLeftAlias`
   - Build JOIN clause: `joinTypeSql quotedRightSchema.quotedRightTable [AS] quotedRightAlias`
   - Build ON clause: use the stored `onClauseSql` as-is (already correct SQL from RexToJoinSqlString).

   ```java
   boolean useAs = !(dialect instanceof OracleSqlDialect);
   String aliasKeyword = useAs ? " AS " : " ";

   // Extract output field names for column aliasing
   List<String> outputFieldNames = new ArrayList<>();
   for (RelDataTypeField f : outputRowType.getFieldList()) {
     outputFieldNames.add(f.getName());
   }

   StringBuilder sql = new StringBuilder();

   // SELECT list
   boolean hasColumns = (leftColumns != null && !leftColumns.isEmpty())
       || (rightColumns != null && !rightColumns.isEmpty());
   if (!hasColumns) {
     sql.append("SELECT *");
   } else {
     sql.append("SELECT ");
     boolean first = true;
     int fieldIdx = 0;
     String quotedLeftAlias = quoteId(dialect, "t1");
     String quotedRightAlias = quoteId(dialect, "t2");

     if (leftColumns != null) {
       for (SchemaPath col : leftColumns) {
         if (!first) sql.append(", ");
         String colName = col.getRootSegment().getPath();
         sql.append(quotedLeftAlias).append(".").append(quoteId(dialect, colName));
         if (fieldIdx < outputFieldNames.size()) {
           String calciteName = outputFieldNames.get(fieldIdx);
           if (!calciteName.equals(colName)) {
             sql.append(useAs ? " AS " : " ").append(quoteId(dialect, calciteName));
           }
         }
         fieldIdx++;
         first = false;
       }
     }
     if (rightColumns != null) {
       for (SchemaPath col : rightColumns) {
         if (!first) sql.append(", ");
         String colName = col.getRootSegment().getPath();
         sql.append(quotedRightAlias).append(".").append(quoteId(dialect, colName));
         if (fieldIdx < outputFieldNames.size()) {
           String calciteName = outputFieldNames.get(fieldIdx);
           if (!calciteName.equals(colName)) {
             sql.append(useAs ? " AS " : " ").append(quoteId(dialect, calciteName));
           }
         }
         fieldIdx++;
         first = false;
       }
     }
   }

   // FROM
   sql.append(" FROM ")
       .append(quoteId(dialect, leftSchema)).append(".").append(quoteId(dialect, leftTable))
       .append(aliasKeyword).append(quoteId(dialect, "t1"));

   // JOIN
   sql.append(" ").append(SqlBuilder.joinTypeToSql(joinType)).append(" ")
       .append(quoteId(dialect, rightSchema)).append(".").append(quoteId(dialect, rightTable))
       .append(aliasKeyword).append(quoteId(dialect, "t2"));

   // ON
   sql.append(" ON ").append(onClauseSql);
   ```

3. Add a private helper method for quoting:
   ```java
   private static String quoteId(SqlDialect dialect, String identifier) {
     // SqlDialect.quoteIdentifier(String) wraps the identifier in dialect-appropriate quotes
     return dialect.quoteIdentifier(identifier);
   }
   ```
   NOTE: Check the actual SqlDialect API. In Calcite 1.22.0, `quoteIdentifier(String)` returns a `String`. If only `quoteIdentifier(StringBuilder, String)` exists, use:
   ```java
   private static String quoteId(SqlDialect dialect, String identifier) {
     StringBuilder buf = new StringBuilder();
     dialect.quoteIdentifier(buf, identifier);
     return buf.toString();
   }
   ```

4. Keep `SqlBuilder.joinTypeToSql()` for the JOIN type string (it's a static utility, no dialect dependency).

5. Pass `Collections.emptyList()` for bindParams to JdbcGroupScan (inline literals, no prepared statement placeholders).

6. The rest of the method (BatchSchema creation, column merging, JdbcGroupScan construction) stays IDENTICAL.
