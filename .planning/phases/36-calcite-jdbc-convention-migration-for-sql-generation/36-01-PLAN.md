Create JdbcCalciteLeaf, createDialect(), and rewrite single-table SQL generation to use Calcite's JdbcRel subtree + JdbcImplementor.

Purpose: Replace SqlBuilder.buildSql() in JdbcScanPrel.getPhysicalOperator() with a proper Calcite JdbcRel subtree that is rendered to SQL via JdbcImplementor + SqlDialect. This is the core architectural change: instead of storing SQL string fragments (whereClause, orderByClause, selectExprs, groupByClause) on JdbcScanPrel, the pushdown rules store Calcite objects (RexNode, RelCollation, ImmutableBitSet, AggregateCall). At getPhysicalOperator() time, these objects are used to build a JdbcRel subtree (JdbcCalciteLeaf -> JdbcFilter -> JdbcProject -> JdbcAggregate -> JdbcSort) which JdbcImplementor renders to SQL. Calcite handles all identifier quoting, dialect-specific syntax (LIMIT vs FETCH FIRST, AS keyword), and SQL composition automatically.

No kernel changes. DrelTransformer untouched per user decision: "limit the intervention on core kernel part."

Output: JdbcCalciteLeaf, createDialect(), rewritten JdbcScanPrel (Calcite object fields + JdbcImplementor rendering), updated pushdown rules storing Calcite objects.

**Rewrite getPhysicalOperator(PhysicalPlanCreator creator):**

```java
// 1. Resolve dialect
StoragePlugin rawPlugin = creator.getContext().getCatalogService()
    .getSource(getPluginId().getName());
JdbcStoragePlugin jdbcPlugin = (rawPlugin instanceof JdbcStoragePlugin)
    ? (JdbcStoragePlugin) rawPlugin : null;
SqlDialect dialect = jdbcPlugin != null
    ? jdbcPlugin.createDialect() : PostgresqlSqlDialect.DEFAULT;

// 2. Create JdbcConvention and trait set
JdbcConvention convention = JdbcConvention.of(dialect, null,
    "DREMIO_JDBC_" + getPluginId().getName());
RelOptCluster cluster = getCluster();
RelTraitSet jdbcTraitSet = cluster.traitSet().replace(convention);

// 3. Determine the base table row type for the leaf.
// This is the FULL table row type (all columns), needed so JdbcFilter/JdbcProject
// can reference columns by index. Use the scan's own row type when no aggregation
// and no projection filtering has altered it.
// NOTE: When filterRex references column indices, those are relative to this rowType.
RelDataType baseRowType = (overrideRowType == null)
    ? deriveRowType() : getTable().getRowType();
// Actually, we need the original table row type always so filter/project indices work.
// The scan's projected rowType may have fewer columns.
// Use getTable().getRowType() which gives the full table type.
// If getTable() returns null, fall back to deriveRowType().
RelDataType fullTableRowType;
try {
  fullTableRowType = getTable().getRowType();
} catch (Exception e) {
  fullTableRowType = deriveRowType();
}

// 4. Build leaf
JdbcCalciteLeaf leaf = new JdbcCalciteLeaf(
    cluster, jdbcTraitSet, fullTableRowType, schemaName, tableName);
RelNode root = leaf;

// 5. Wrap with JdbcFilter if filterRex present
if (filterRex != null) {
  root = new JdbcRules.JdbcFilter(cluster, jdbcTraitSet, root, filterRex);
}

// 6. Wrap with JdbcProject for column projection (when NO aggregation)
// When aggregation is present, the JdbcAggregate handles the SELECT list.
if (!hasAggregation() && getProjectedColumns() != null
    && !getProjectedColumns().isEmpty()) {
  RexBuilder rexBuilder = cluster.getRexBuilder();
  RelDataType inputRowType = root.getRowType();
  List<RexNode> projects = new ArrayList<>();
  List<String> fieldNames = new ArrayList<>();
  for (SchemaPath col : getProjectedColumns()) {
    String colName = col.getRootSegment().getPath();
    int idx = -1;
    for (int i = 0; i < inputRowType.getFieldCount(); i++) {
      if (inputRowType.getFieldList().get(i).getName().equals(colName)) {
        idx = i;
        break;
      }
    }
    if (idx >= 0) {
      projects.add(rexBuilder.makeInputRef(inputRowType.getFieldList().get(idx).getType(), idx));
      fieldNames.add(colName);
    }
  }
  if (!projects.isEmpty()) {
    RelDataType projRowType = cluster.getTypeFactory().createStructType(
        projects.stream().map(RexNode::getType).collect(Collectors.toList()),
        fieldNames);
    root = new JdbcRules.JdbcProject(cluster, jdbcTraitSet, root, projects, projRowType);
  }
}

// 7. Wrap with JdbcAggregate if aggregation pushed
if (hasAggregation()) {
  try {
    root = new JdbcRules.JdbcAggregate(
        cluster, jdbcTraitSet, root, groupSet, null, aggCalls);
  } catch (org.apache.calcite.rel.InvalidRelException e) {
    throw new IOException("Invalid aggregation for JDBC pushdown: " + e.getMessage(), e);
  }
}

// 8. Wrap with JdbcSort for ORDER BY and/or LIMIT
if (collation != null || limit != null) {
  RexBuilder rexBuilder = cluster.getRexBuilder();
  RelCollation sortCollation = collation != null
      ? collation : org.apache.calcite.rel.RelCollations.EMPTY;
  RexNode fetchNode = limit != null
      ? rexBuilder.makeLiteral(limit,
          cluster.getTypeFactory().createSqlType(
              org.apache.calcite.sql.type.SqlTypeName.INTEGER), true)
      : null;
  root = new JdbcRules.JdbcSort(
      cluster, jdbcTraitSet, root, sortCollation, null, fetchNode);
}

// 9. Render SQL via DremioJdbcImplementor (NOT JdbcImplementor — our custom
//    subclass handles JdbcCalciteLeaf dispatch via visit(JdbcCalciteLeaf))
org.apache.calcite.adapter.java.JavaTypeFactory typeFactory =
    (org.apache.calcite.adapter.java.JavaTypeFactory) cluster.getTypeFactory();
DremioJdbcImplementor implementor = new DremioJdbcImplementor(dialect, typeFactory);
SqlImplementor.Result result = implementor.implement(root);
String sql = result.asStatement().toSqlString(dialect).getSql();
```
