**Create `JdbcPushAggWithExpressionsHep.java`** — a new HEP-phase rule that matches `AggregatePrel(ProjectPrel(JdbcScanPrel))` where the ProjectPrel contains function expressions in GROUP BY key positions or aggregate operand positions. This mirrors `JdbcPushSortWithExpressionsHep` exactly in structure.

**Class structure:**
```java
package com.dremio.plugins.jdbc.planning;

public final class JdbcPushAggWithExpressionsHep extends RelOptRule {
  private final PushdownFunctionRegistry registry;

  public JdbcPushAggWithExpressionsHep(PushdownFunctionRegistry registry) {
    super(RelOptRule.operand(AggregatePrel.class, RelOptRule.any()),
        "JdbcPushAggWithExpressionsHep");
    this.registry = registry;
  }
```

**`matches()` guards** (copy all guards from `JdbcPushAggIntoScan.matches()`):
1. `agg.getOperatorPhase() != AggregatePrel.OperatorPhase.PHASE_1of1` -> return false
2. Find `[ProjectPrel, JdbcScanPrel]` via `JdbcPushSortWithExpressionsHep.findProjectAndScan(agg.getInput(), 2)` — return false if null
3. `scan.hasAggregation()` -> return false
4. Copy the DISTINCT/filterArg/unsupported-kind guard loops from `JdbcPushAggIntoScan.matches()` exactly
5. Check that at least one project expression at a `groupSet` bit OR `AggregateCall.getArgList()` position is a non-`RexInputRef` (function expression) — otherwise the existing Volcano `JdbcPushAggIntoScan.INSTANCE` handles it
6. Validate ALL project expressions at groupSet bit positions and aggCall arg positions via `registry.isExpressionPushable()` — return false if any fail

**`onMatch()` logic:**
1. Extract `AggregatePrel agg`, find `[ProjectPrel, JdbcScanPrel]` via `findProjectAndScan()`
2. Get `List<RexNode> projExprs = projectPrel.getProjects()`
3. For each `groupSet` bit `i`: extract `projExprs.get(i)`. Separate into:
   - If `RexInputRef`: record the scan-column index it references (the `RexInputRef.getIndex()`)
   - If `RexCall` (function expression): record it as a GROUP BY expression to be stored on the scan
4. For each `AggregateCall.getArgList()` entry `j`: extract `projExprs.get(j)`. Same separation.
5. Build a new `ImmutableBitSet` for groupSet where:
   - `RexInputRef` entries: use the underlying scan column index directly
   - Function expression entries: use indices `fullTableFieldCount + k` (extended columns)
6. Build new `List<AggregateCall>` with remapped arg indices (same logic)
7. Build the list of group-key expressions (`List<RexNode>`) and agg-operand expressions (`List<RexNode>`) that need to be materialized as extended project columns
8. Call a new `scan.cloneWithAggregationExpressions(groupSet, aggCalls, newRowType, groupKeyExpressions, aggOperandExpressions)` method
