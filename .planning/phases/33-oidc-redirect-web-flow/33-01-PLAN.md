<objective>
Create OidcStateStore and OidcSessionStore in the keycloak module, add oauth2-oidc-sdk Maven dependency, and wire both stores in DACDaemonModule.

Purpose: These are the two in-process stores required by the OIDC redirect flow (Plan 02). OidcStateStore holds pending PKCE state for CSRF protection (OIDC-03). OidcSessionStore holds id_token_hint for RP-Initiated Logout (LOUT-02). The oauth2-oidc-sdk dependency is needed by OidcResource (Plan 02) for AuthorizationRequest.Builder and TokenRequest.

Output: Two new Java classes with tests, updated pom.xml, updated DACDaemonModule keycloak branch bindings.
