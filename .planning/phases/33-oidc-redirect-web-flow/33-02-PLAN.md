<objective>
Create OidcResource with GET /api/v3/oidc/login and GET /api/v3/oidc/callback endpoints implementing the full OIDC Authorization Code Flow with PKCE.

Purpose: This is the core OIDC redirect flow. The login endpoint initiates the Keycloak redirect with PKCE parameters. The callback endpoint exchanges the authorization code for tokens, JIT-provisions the user, syncs roles, mints a Dremio session token, stores the id_token for logout, and redirects the browser to the SSO landing page.

Output: OidcResource.java (production) + TestOidcResource.java (unit tests with Mockito).
</objective>

    OidcResource.java in dac/backend/src/main/java/com/dremio/dac/resource/:
    - @APIResource annotation (registers under /api/v3/*)
    - @Path("/oidc")
    - NO @Secured annotation (unauthenticated browser endpoints)
    - Field injection with @Inject @Nullable for keycloak-specific dependencies (same pattern as DACAuthFilter):
      - @Inject @Nullable OidcStateStore oidcStateStore
      - @Inject @Nullable OidcSessionStore oidcSessionStore
      - @Inject @Nullable OidcTokenValidator oidcTokenValidator
      - @Inject @Nullable JitUserProvisioner jitUserProvisioner

      - @Inject @Nullable KeycloakConfig keycloakConfig
      - @Inject TokenManager tokenManager (always available)
      - @Inject SabotContext sabotContext (always available)
    - private static final Logger logger

    GET /login (initiateLogin):
    1. Guard: if oidcStateStore == null -> return Response.status(503).entity("Keycloak auth not enabled").build()
    2. Create CodeVerifier (new CodeVerifier()) and State (new State())
    3. Build authorization URI:
       - authorizationEndpoint = URI.create(keycloakConfig.getIssuerUrl() + "/protocol/openid-connect/auth")
       - AuthorizationRequest.Builder with ResponseType.Value.CODE, ClientID(keycloakConfig.getClientId())
       - .endpointURI(authorizationEndpoint)
       - .redirectionURI(URI.create(keycloakConfig.getRedirectUri()))
       - .scope(new Scope("openid", "profile", "email"))
       - .state(state)
       - .codeChallenge(codeVerifier, CodeChallengeMethod.S256)
       - .build()
    4. oidcStateStore.put(state.getValue(), codeVerifier.getValue())
    5. return Response.temporaryRedirect(authRequest.toURI()).build()

    GET /callback (handleCallback):
    1. @QueryParam("code") String code, @QueryParam("state") String state, @Context HttpServletRequest request
    2. Guard: if state == null || code == null -> 400 "Missing code or state"
    3. String storedVerifier = oidcStateStore.removeIfValid(state)
    4. If storedVerifier == null -> 400 "Invalid or expired state"
    5. Call exchangeCodeForTokens(code, storedVerifier) -> OidcTokenExchangeResult(accessToken, idToken)
    6. If exchange failed (returns null or throws) -> 502 Bad Gateway
    7. KeycloakTokenDetails ktd = oidcTokenValidator.validateWithClaims(accessToken)
    8. jitUserProvisioner.provision(ktd.getUsername(), ktd.getEmail()) -- catch IOException, log, continue
    9. keycloakRoleSyncer.syncRoles(ktd.getUsername(), ktd.getRealmRoles())
    10. Ensure homespace: try { CatalogServiceHelper.ensureUserHasHomespace(sabotContext.getNamespaceService(SystemUser.SYSTEM_USERNAME), ktd.getUsername(), sabotContext.getOptionManager()); } catch (Exception e) { logger.warn(...); } -- log failures, do NOT abort login
    11. TokenDetails dremioToken = tokenManager.createToken(ktd.getUsername(), request.getRemoteAddr())
    12. oidcSessionStore.put(dremioToken.token, idToken) -- LOUT-02
    13. URI landingUri = URI.create("/login/sso/landing#token=" + dremioToken.token)
    14. return Response.temporaryRedirect(landingUri).build()

    Protected method exchangeCodeForTokens(String code, String codeVerifier) -> OidcTokenExchangeResult:
    - Build TokenRequest with AuthorizationCodeGrant, ClientSecretBasic, CodeVerifier
    - tokenEndpoint = URI.create(keycloakConfig.getIssuerUrl() + "/protocol/openid-connect/token")
    - Execute: tokenRequest.toHTTPRequest().send()
    - Parse: OIDCTokenResponseParser.parse(httpResponse)
    - Check indicatesSuccess()
    - Return new OidcTokenExchangeResult(accessToken.getValue(), idToken.serialize())
    - Throws IOException on HTTP failure, returns null on Keycloak error response

    Private static inner class OidcTokenExchangeResult with (String accessToken, String idToken).
