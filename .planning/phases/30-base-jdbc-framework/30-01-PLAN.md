  <name>Task 2: Implement BaseJdbcConf, JdbcConnectionPool, and JdbcStoragePlugin with health check</name>
  <files>

  <action>
1. **BaseJdbcConf.java** — Abstract generic class extending `ConnectionConf<T, P>`:
   - Type parameters: `<T extends BaseJdbcConf<T, P>, P extends StoragePlugin>`
   - Fields with `@Tag` annotations (Protostuff serialization):
     - `@Tag(1) public int poolSize = 5;`
     - `@Tag(2) @NotMetadataImpacting public int idleTimeoutMs = 600_000;`
     - `@Tag(3) @NotMetadataImpacting public String validationQuery = "SELECT 1";`
   - Abstract method: `public abstract String jdbcUrl();` — concrete connectors override to provide the JDBC URL
   - Abstract method: `public abstract String driverClassName();` — concrete connectors specify the JDBC driver class
   - Do NOT put `@SourceType` on this class — that goes on concrete subclasses only (per research anti-pattern guidance)
   - Import from `io.protostuff.Tag` and `com.dremio.exec.catalog.conf.NotMetadataImpacting`
   - Reference `ElasticsearchConf.java` for import patterns and class structure

2. **JdbcConnectionPool.java** — Thin wrapper around HikariCP:
   - Constructor takes `BaseJdbcConf<?, ?>` parameter
   - Creates `HikariConfig` with:
     - `setJdbcUrl(conf.jdbcUrl())`
     - `setDriverClassName(conf.driverClassName())` (if non-null)
     - `setMaximumPoolSize(conf.poolSize)`
     - `setIdleTimeout(conf.idleTimeoutMs)`
     - `setConnectionTestQuery(conf.validationQuery)`
   - Wraps a `HikariDataSource` field
   - Public method: `Connection getConnection() throws SQLException` — delegates to `dataSource.getConnection()`
   - Public method: `void close()` — calls `dataSource.close()`
   - Implements `AutoCloseable`

3. **JdbcStoragePlugin.java** — Implements `StoragePlugin`:
   - Constructor receives `BaseJdbcConf<?, ?> conf` and `SabotContext context` and `String name`
   - Field: `JdbcConnectionPool pool` (null until start())
   - `start()`: creates `JdbcConnectionPool` from `conf`
   - `close()`: closes pool if non-null
   - `getState()`: executes `conf.validationQuery` via a connection from the pool:
     - Success → return `SourceState.GOOD`
     - SQLException → return `SourceState.badState("Validation failed: " + e.getMessage())`
     - If pool is null → return `SourceState.badState("Source not started")`
   - `getPool()`: public getter returning the `JdbcConnectionPool` (needed by RecordReader in plan 02)
   - For now, stub required methods from `StoragePlugin` interface (e.g., `hasAccessPermission()` returns true, `supportsRead()` returns true)
   - Reference `ElasticsearchStoragePlugin.java` and `InfoSchemaStoragePlugin.java` for the full interface method list and stubs
  </action>
