  <action>
    Create `PushdownFunctionRegistry.java` as an interface in the `planning` package:
    - Method: `boolean isFunctionPushable(SqlOperator op)` — checks if a specific SQL operator can be pushed to the remote source.
    - Default method: `boolean isExpressionPushable(RexNode expr)` — recursive RexNode tree walk using `RexVisitorImpl<Boolean>`:
      - `visitInputRef()` -> true
      - `visitLiteral()` -> true
      - `visitCall()`:
        - If kind belongs to COMPARISON, LOGICAL, or is PLUS/MINUS/TIMES/DIVIDE, IS_NULL/IS_NOT_NULL, LIKE, BETWEEN, IN/NOT_IN, NOT, CASE -> recurse into operands
        - Otherwise check `isFunctionPushable(call.getOperator())` -> if false return false, else recurse operands
      - Any other RexNode type (e.g. RexFieldAccess, RexDynamicParam) -> return false (not pushable)
    - The default `isExpressionPushable` method handles the recursive composition checking. Each operand must return Boolean.TRUE; use `== Boolean.TRUE` guard against null.

    Create `StandardPushdownFunctionRegistry.java` implementing `PushdownFunctionRegistry`:
    - Singleton: `public static final StandardPushdownFunctionRegistry INSTANCE`
    - Whitelisted SqlKind set (EnumSet): CAST, FLOOR, CEIL, TRIM, LTRIM, RTRIM, EXTRACT, COALESCE, NULLIF
    - Whitelisted function names (ImmutableSet of uppercase strings): "UPPER", "LOWER", "ABS", "ROUND", "SUBSTRING", "CHAR_LENGTH", "CHARACTER_LENGTH", "LENGTH"
    - `isFunctionPushable(SqlOperator op)`:
      - If `WHITELISTED_KINDS.contains(op.getKind())` -> true
      - If `op.getKind() == SqlKind.OTHER_FUNCTION` and `WHITELISTED_FUNCTION_NAMES.contains(op.getName().toUpperCase(Locale.ROOT))` -> true
      - Otherwise false

    Add to `JdbcStoragePlugin.java`:
    - New method: `public PushdownFunctionRegistry getPushdownFunctionRegistry()` returning `StandardPushdownFunctionRegistry.INSTANCE`
    - This allows per-dialect subclasses (PostgresConf.newPlugin(), OracleConf.newPlugin()) to override with dialect-specific registries in future phases if needed.

    Create `TestPushdownFunctionRegistry.java` in the test package:
    - Test `isFunctionPushable()` returns true for each whitelisted SqlKind (use `SqlStdOperatorTable.UPPER`, `SqlStdOperatorTable.LOWER`, `SqlStdOperatorTable.ABS`, `SqlStdOperatorTable.ROUND`, `SqlStdOperatorTable.FLOOR`, `SqlStdOperatorTable.CEIL`, `SqlStdOperatorTable.TRIM`, `SqlStdOperatorTable.EXTRACT`, `SqlStdOperatorTable.COALESCE`, `SqlStdOperatorTable.NULLIF`, `SqlStdOperatorTable.CAST`, `SqlStdOperatorTable.SUBSTRING`)
    - Test `isFunctionPushable()` returns false for a non-whitelisted function (e.g. `SqlStdOperatorTable.LOCALTIME` or any function not in the whitelist)
    - Test `isExpressionPushable()` with a mock/constructed RexNode:
      - Create a `RexBuilder` using `JavaTypeFactoryImpl` as the type factory
      - Build RexLiteral -> true
      - Build RexInputRef -> true
      - Build a RexCall with UPPER(RexInputRef) -> true
      - Build a RexCall with a non-whitelisted function -> false
    - Use JUnit 4 (`@Test`, `assertTrue`, `assertFalse`)
