CRITICAL: `super.start()` MUST be called first. The parent's `start()` calls `createCatalog()` which initializes the `CatalogAccessor` and the underlying `RESTCatalog`. Only after this can we read `RESTCatalog.properties()`.

2. **Add `detectNessieBackend()` method** (private):
```java
private void detectNessieBackend() {
    try {
        Catalog catalog = getCatalogAccessor().getCatalog();
        if (!(catalog instanceof RESTCatalog)) {
            logger.warn("enableNessie is true but catalog is not a RESTCatalog instance ({}). "
                + "Nessie features will be disabled.", catalog.getClass().getSimpleName());
            return;
        }

        Map<String, String> props = ((RESTCatalog) catalog).properties();
        String isNessieProp = props.get(NESSIE_IS_NESSIE_CATALOG_KEY);

        if (!"true".equals(isNessieProp)) {
            logger.warn("enableNessie is true but the backend does not appear to be a Nessie catalog "
                + "({}={} in config response). Nessie features will be disabled.",
                NESSIE_IS_NESSIE_CATALOG_KEY, isNessieProp);
            return;
        }

        // Read default branch
        String branch = props.get(NESSIE_DEFAULT_BRANCH_KEY);
        if (branch == null || branch.isEmpty()) {
            logger.warn("Nessie backend detected but default branch name not found in config response "
                + "({}=null). Falling back to '{}'.",
                NESSIE_DEFAULT_BRANCH_KEY, NESSIE_DEFAULT_BRANCH_FALLBACK);
            branch = NESSIE_DEFAULT_BRANCH_FALLBACK;
        }

        this.defaultBranch = branch;
        this.nessieDetected = true;
        logger.info("Nessie backend detected for source '{}'. Default branch: '{}'.",
            getName(), defaultBranch);
    } catch (Exception e) {
        logger.warn("Failed to detect Nessie backend for source '{}'. "
            + "Nessie features will be disabled.", getName(), e);
        this.nessieDetected = false;
        this.defaultBranch = null;
    }
}
```

IMPORTANT implementation notes:
- `getCatalogAccessor().getCatalog()` triggers lazy initialization of the RESTCatalog (via ExpiringCatalogCache.get()) which calls the config endpoint. Look at `IcebergRestCatalogAccessor` to find the accessor method that returns the underlying catalog -- it likely exposes it through a method or the `catalogSupplier.get()` pattern shown in `getDefaultBaseLocation()`. If `getCatalog()` does not exist on `CatalogAccessor`, use the same pattern as `getDefaultBaseLocation()` by accessing the catalog through the accessor. Check the actual `CatalogAccessor` and `IcebergRestCatalogAccessor` interfaces to find the right method.
- All exceptions are caught and logged as warnings -- the source MUST still start normally even if detection fails. Never throw from this method.
- String comparison: use `"true".equals(isNessieProp)` (not `Boolean.parseBoolean`) to avoid null issues and be explicit about the expected value.
