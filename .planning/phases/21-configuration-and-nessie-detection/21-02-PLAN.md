<objective>
Implement Nessie backend auto-detection and default branch discovery in the RESTCATALOG plugin.

Purpose: When a user sets `enableNessie=true` (from Plan 01), the plugin must determine whether the backend is actually Nessie and discover the default branch name -- all by reading properties from the already-initialized RESTCatalog config endpoint response. This is the runtime counterpart to Plan 01's config-only changes. The detected state (`isNessieDetected`, `defaultBranch`) will be consumed by Phase 22 when implementing `SupportsBranchAwareRestCatalog`. When `enableNessie=false`, absolutely no new code executes (CMP-01).

Output: Modified `RestIcebergCatalogPlugin.java` with `start()` override, detection logic, and public getters. Modified `IcebergRestCatalogAccessor.java` with new `getRestCatalogProperties()` method.
</objective>

**4. Add detectNessieBackend() private method** immediately after `start()`:

```java
private void detectNessieBackend() {
    if (!enableNessie) {
        return; // CMP-01: no new code runs when enableNessie=false
    }

    try {
        CatalogAccessor accessor = getCatalogAccessor();
        Preconditions.checkState(
            accessor instanceof IcebergRestCatalogAccessor,
            "Expected IcebergRestCatalogAccessor but got %s",
            accessor.getClass().getSimpleName());
        Map<String, String> props =
            ((IcebergRestCatalogAccessor) accessor).getRestCatalogProperties();

        String isNessieCatalog = props.get(NESSIE_IS_NESSIE_CATALOG);
        if ("true".equals(isNessieCatalog)) {
            this.isNessieDetected = true;
            String branch = props.get(NESSIE_DEFAULT_BRANCH_NAME);
            if (branch == null || branch.isEmpty()) {
                logger.warn(
                    "Nessie backend detected but default branch name not found in config response. "
                        + "Falling back to '{}'.",
                    DEFAULT_BRANCH_FALLBACK);
                branch = DEFAULT_BRANCH_FALLBACK;
            }
            this.defaultBranch = branch;
            logger.info("Nessie backend detected for source '{}'. Default branch: {}",
                getName(), this.defaultBranch);
        } else {
            logger.warn(
                "enableNessie is true for source '{}' but backend does not appear to be Nessie "
                    + "(nessie.is-nessie-catalog not found in config response). "
                    + "Nessie features will be disabled.",
                getName());
            this.isNessieDetected = false;
        }
    } catch (Exception e) {
        logger.warn(
            "Failed to detect Nessie backend for source '{}'. "
                + "Nessie features will be disabled.",
            getName(), e);
        this.isNessieDetected = false;
        this.defaultBranch = DEFAULT_BRANCH_FALLBACK;
    }
}
```
