Purpose: Enable branch-aware queries (Phase 23) by providing per-branch RESTCatalog instances that are cached, bounded, TTL-evicted, and properly closed on eviction. Each branch gets its own IcebergRestCatalogAccessor with an isolated table cache, preventing cross-branch cache poisoning.

Output: BranchAwareCatalogAccessorCache class, support keys for cache tuning, and plugin integration (initialization, factory, lifecycle, public API).
</objective>

    **3. Add the factory method `createBranchScopedAccessor(String branchName)`:**

    Add as a private method. This mirrors the existing `createCatalog(config)` pattern but with a branch-specific URI:
    ```java
    private IcebergRestCatalogAccessor createBranchScopedAccessor(String branchName) {
      Configuration config = getFsConfCopy();
      Map<String, String> properties = buildCatalogProperties(config);
      // Append branch name to base REST endpoint to create branch-scoped URI
      // e.g., "http://nessie:19120/iceberg" -> "http://nessie:19120/iceberg/dev"
      String branchUri = restEndpoint + "/" + branchName;
      properties.put(CatalogProperties.URI, branchUri);

      Supplier<Catalog> catalogSupplier = () ->
          CatalogUtil.loadCatalog(
              restCatalogImpl().getName(), catalogName(), properties, config);

      return new IcebergRestCatalogAccessor(
          catalogSupplier,
          optionManager,
          getAllowedNamespaces(),
          isRecursiveAllowedNamespaces());
    }
    ```

    Note: Do NOT URL-encode the branch name here. Nessie Iceberg REST expects the raw branch name as a path segment. Branch names with `/` (like `feature/foo`) are handled by Nessie's prefix decoder using the pipe separator convention, not URL encoding. Simple branch names like `main`, `dev`, `staging` work as-is.

    **4. Add public accessor method `getCatalogAccessorForBranch(String branchName)`:**

    ```java
    /**
     * Returns a CatalogAccessor scoped to the given branch. The accessor is cached --
     * repeated calls with the same branch return the same instance. Each branch accessor
     * has its own isolated table cache (INF-02).
     *
     * @throws IllegalStateException if Nessie was not detected during start()
     */
    public CatalogAccessor getCatalogAccessorForBranch(String branchName) {
      Preconditions.checkState(isNessieDetected && branchAccessorCache != null,
          "Branch-aware access requires Nessie-detected source. isNessieDetected=%s",
          isNessieDetected);
      return branchAccessorCache.getOrCreate(branchName);
    }
    ```

    **5. Override close() to clean up the branch cache:**

    Add a `close()` override. The parent `IcebergCatalogPlugin.close()` handles the default `catalogAccessor` and `hadoopFs`. We need to additionally close the branch cache:
    ```java
    @Override
    public void close() throws Exception {
      try {
        if (branchAccessorCache != null) {
          branchAccessorCache.close();
          branchAccessorCache = null;
        }
      } catch (Exception e) {
        logger.warn("Failed to close branch accessor cache for source '{}'", getName(), e);
      }
      super.close();
    }
    ```

    Call `branchAccessorCache.close()` BEFORE `super.close()` so branch accessors are closed before the default accessor. This is a precaution in case any branch accessor references shared state.
