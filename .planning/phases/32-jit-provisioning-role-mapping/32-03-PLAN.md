Create `KeycloakRoleSyncer` in `services/keycloak` package:

```java
public class KeycloakRoleSyncer {
  private static final org.slf4j.Logger logger = org.slf4j.LoggerFactory.getLogger(KeycloakRoleSyncer.class);

  private final RbacService rbacService;
  private final RoleStore roleStore;
  private final KeycloakConfig keycloakConfig;

  public KeycloakRoleSyncer(RbacService rbacService, RoleStore roleStore, KeycloakConfig keycloakConfig) {
    this.rbacService = rbacService;
    this.roleStore = roleStore;
    this.keycloakConfig = keycloakConfig;
  }

  /**
   * Syncs Keycloak realm_access.roles to Dremio RBAC memberships.
   * - Both modes: grants roles present in token that match existing Dremio roles
   * - Additive: never removes any membership
   * - Authoritative: revokes keycloak-sourced memberships no longer in token
   * Idempotent and exception-safe: never throws on role sync issues.
   */
  public void syncRoles(String username, List<String> keycloakRoles) {
    try {
      syncRolesInternal(username, keycloakRoles);
    } catch (Exception e) {
      // Role sync must never abort the request (ROLE-04 spirit: graceful degradation)
      logger.warn("Role sync failed for user '{}': {}", username, e.getMessage());
    }
  }

  private void syncRolesInternal(String username, List<String> keycloakRoles) throws RbacEntityNotFoundException {
    // ROLE-04: Filter to only roles that exist in Dremio RBAC
    // ADMIN is a synthetic built-in role (not in roleStore) -- check separately
    Set<String> validKeycloakRoles = new HashSet<>();
    for (String role : keycloakRoles) {
      if (RbacService.ADMIN_ROLE_ID.equals(role) || roleStore.get(role) != null) {
        validKeycloakRoles.add(role);
      } else {
        logger.debug("Keycloak role '{}' has no Dremio RBAC role -- skipping", role);
      }
    }

    // Get current memberships for the user
    List<Membership> currentMemberships = rbacService.listMembershipsByUser(username);
    Set<String> keycloakSourcedRoles = currentMemberships.stream()
        .filter(m -> "keycloak".equals(m.getSource()))
        .map(Membership::getRoleId)
        .collect(Collectors.toSet());

    // Grant roles present in token but not yet keycloak-sourced in Dremio
    for (String roleId : validKeycloakRoles) {
      if (!keycloakSourcedRoles.contains(roleId)) {
        try {
          rbacService.addMembership(username, roleId, "keycloak", "keycloak");
        } catch (RbacEntityAlreadyExistsException e) {
          // Already exists (manually assigned or concurrent sync) -- silently ignore
          logger.debug("Membership already exists for {}:{} -- skipping", username, roleId);
        }
      }
    }

    // Authoritative mode: revoke keycloak-sourced roles no longer in token
    if (!keycloakConfig.isAdditive()) {
      for (String existingKcRole : keycloakSourcedRoles) {
        if (!validKeycloakRoles.contains(existingKcRole)) {
          try {
            rbacService.removeMembership(username, existingKcRole);
          } catch (RbacEntityNotFoundException e) {
            logger.debug("Membership already removed for {}:{} -- skipping", username, existingKcRole);
          }
        }
      }
    }
    // Additive mode: manually-assigned roles (source="") are never touched (ROLE-02)
  }
}
```

**Testing approach:** Use Mockito mocks for `RbacService`, `RoleStore`, and `KeycloakConfig`. Verify interactions via `verify(rbacService).addMembership(...)` and `verify(rbacService, never()).removeMembership(...)`. For the existing membership scenario, mock `listMembershipsByUser()` to return `Membership` objects with appropriate `source` values.

**CRITICAL per Research Pitfall 2:** Always check `"keycloak".equals(m.getSource())`, never `m.getSource() == null`. Proto3 default is empty string, not null.

**CRITICAL per Research Pitfall 4:** Unknown Keycloak roles must NOT throw -- check `roleStore.get(roleId) != null` before calling `addMembership()`.

**CRITICAL per Research anti-pattern:** `syncRoles()` wraps all logic in try-catch. Role sync failure must never return 401 to the API caller. Log at WARN and continue.

**Note on RoleStore injection:** `KeycloakRoleSyncer` needs `RoleStore` (not just `RbacService`) because `RbacService.addMembership()` throws `RbacEntityNotFoundException` for non-existent roles, and we want to pre-filter silently. The per-role `roleStore.get(roleId)` check is simpler than adding a new method to `RbacService` (see Research Open Question 3).
