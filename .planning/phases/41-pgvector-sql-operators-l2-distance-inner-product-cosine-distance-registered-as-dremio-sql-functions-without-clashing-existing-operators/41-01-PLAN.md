All three inner classes share this structure:
- @FunctionTemplate(name = "...", scope = FunctionTemplate.FunctionScope.SIMPLE, nulls = FunctionTemplate.NullHandling.INTERNAL)
- public static class XxxFunction implements SimpleFunction
- @Param FieldReader left; @Param FieldReader right;
- @Output NullableFloat8Holder out;
- @Inject FunctionErrorContext errCtx;
- public void setup() {} (empty)
- public void eval() with the logic below

eval() pattern for all three (use fully-qualified class names inside eval() body):

Step 1 — null check (INTERNAL null handling requires this manually):
  if (!left.isSet() || left.readObject() == null || !right.isSet() || right.readObject() == null) {
    out.isSet = 0; return;
  }

Step 2 — cast to UnionListReader:
  org.apache.arrow.vector.complex.impl.UnionListReader lReader =
      (org.apache.arrow.vector.complex.impl.UnionListReader) left;
  org.apache.arrow.vector.complex.impl.UnionListReader rReader =
      (org.apache.arrow.vector.complex.impl.UnionListReader) right;

Step 3 — dimension check:
  if (lReader.size() != rReader.size()) {
    throw errCtx.error()
        .message("FUNCTION_NAME: vector dimension mismatch: %d vs %d", lReader.size(), rReader.size())
        .build();
  }

Step 4 — computation (differs per function):

L2Distance (name = "l2_distance"):
  double sum = 0.0;
  while (lReader.next() && rReader.next()) {
    double diff = lReader.reader().readFloat() - rReader.reader().readFloat();
    sum += diff * diff;
  }
  out.isSet = 1;
  out.value = java.lang.Math.sqrt(sum);

CosineDistance (name = "cosine_distance"):
  double dot = 0.0, normA = 0.0, normB = 0.0;
  while (lReader.next() && rReader.next()) {
    double ai = lReader.reader().readFloat();
    double bi = rReader.reader().readFloat();
    dot += ai * bi;
    normA += ai * ai;
    normB += bi * bi;
  }
  // Zero-magnitude vector: return null (conventional behavior, avoids NaN/Infinity)
  if (normA == 0.0 || normB == 0.0) {
    out.isSet = 0;
    return;
  }
  out.isSet = 1;
  out.value = 1.0 - (dot / (java.lang.Math.sqrt(normA) * java.lang.Math.sqrt(normB)));

InnerProduct (name = "inner_product"):
  // pgvector convention: negative dot product (lower = more similar)
  double sum = 0.0;
  while (lReader.next() && rReader.next()) {
    sum += (double) lReader.reader().readFloat() * (double) rReader.reader().readFloat();
  }
  out.isSet = 1;
  out.value = -sum;

No @Workspace needed — all accumulators are local double variables in eval().
No OutputDerivation needed — NullableFloat8Holder always produces DOUBLE, which is OutputDerivation.Default.
Do NOT use NullHandling.NULL_IF_NULL — it does not work with FieldReader params.
Do NOT add type checks for MinorType inside eval() — the dimension mismatch check is sufficient. If non-LIST inputs are passed, the cast to UnionListReader will throw a ClassCastException which is acceptable behavior (the function signature contract is LIST<FLOAT4>).
